# OpenFill for PhotoCraft development notes

MiniMax H3 Image uses ComfyUI’s native H3 Image conditioning node and a red-marked locator as the sole conditioning image for Remove. Discover the INT8 encoder before NVFP4 when both are available, because Ada GPUs may not support the fused NVFP4 path. H3 renders near 4 MP and is resized to the crop before applying hard selection support; the original soft selection is applied once on insertion. Existing-server discovery requires the exact diffusion model, image VAE and compatible 32B encoder. This integration does not install H3 into the managed engine. Run the H3 discovery and graph tests along with the companion removal tests; inspect actual GPU results separately.


Saved ComfyUI servers live in the profile's `openfill/config.json` under `comfy_servers`. Preserve built-in source IDs on migration and keep SSH forwarding ports distinct for each endpoint. Engine routing remembers a managed profile's shared override separately so the original local setup is available again. Discovery runs on request and checks ComfyUI status at the standard ports and at each address saved in the user’s profile. Test adding from each panel, offline saving, source changes during jobs, and persistence after restart. On macOS, updating the companion must preserve an existing native launcher and its local-network permission.

PhotoCraft accepts whole-pixel selection expansion from 1 to 500. Keep the slider's initial 1–64 span for fine adjustments and extend it for a larger typed amount. Save the numeric preference to the companion profile only after PhotoCraft successfully expands the selection. When polling the shared value in the other panel, preserve any unsubmitted draft. Native labels sharing a row need `ui.small(..., wrap=0)`. The default width fills the entire row and can hide the field or slider. Verify that both widgets are mapped at the standard panel width, type into the visible field, measure the selection's four edges, and check Undo.

Box gestures start inside the displayed image, exclude the letterbox, and clip the release to the image edge. Keep the original composite for small crops. Rank instance masks by how closely they fit the box. If a crop cuts off the candidate, retry on the full image. Test reverse drags, Escape, misses and normal clicks. Only the model's matte enters the PhotoCraft undo history.

Engine routing belongs to the companion profile. The shared engine is the default for every operation, including Select on a 0.17 profile with a helper installed. In Multi-engine, derive the destination from the submitted job, and use it for the model inventory, removal advice, actual GPU work and cancellation. Each panel requests inventory by its own mode, since the browser and native panels can show different tabs at the same time. Keep per-engine edit preferences separate from the shared configuration. Tab changes should never submit a prompt or evict models. When checking residency, compare the servers and returned mattes across actual jobs.

Select is a separate tool in both panels. Keep the existing internal `fill` key for Edit and legacy menu links; managed Expand/Create are secondary Edit tools. The picker compares the current document **and selection revision** to the preview, including when no selection exists. Never substitute a bounding rectangle or the nearest mask for a missed click. Submit the model's actual per-instance mattes and hit-test the click in image coordinates (exclude the preview's letterbox). The coffee photo distinguishes the ceramic cup, its transparent/partly excluded contents, the saucer, and the spoon. A description can target a different part of the same object. Preserve soft edges while dropping near-zero specks that enlarge selection bounds.

Apply a matte by importing its transparency from a temporary full-canvas RGBA document with `select.loadSelection`. Here `document` is the **source** tab; the active tab receives the selection. Recheck the target after inference and before import. Grow uses PhotoCraft's `select.modify.expand`, independent of ComfyUI and generation settings. Test the real mask after two grows and undo both individually; also test a click on empty background and switching tabs during inference.

When Local duplicates an unrelated object, inspect the donor pixels on the active source. An unrestricted content-aware fill copied a distant white rider into a dark patterned sky. Pass an alpha channel of eligible patch centers into PhotoCraft's custom sampling mode. Build the channel from a band around the actual lasso, give excluded pixels a patch margin, then reload the removal selection in the scratch document. Compare against the unmodified source and the failed render on the same selection.

Check Remove variation counts at three points: what each panel submits, what the backend actually renders, and the composited pixels PhotoCraft displays while switching choices. A different seed cannot vary LaMa/MAT. Transform the source, mask and tile geometry together and undo the transform on the result. Preserve the normal first view. Flat lighting can give the same result in every direction; compare under the final mask and report the number of distinct choices.

Automatic removal advice uses the read-only `document.sampleColor` command and the active selection bounds. A narrow sampling ring can mistake a defocused form for a flat wall. Checking how lighting changes farther out helped on a sticker over a clock and a tag on lunar terrain. Reserve the full mask export for the requested removal. Confirm the same stamped selection and source at submission.

Inspect crops against the actual mask. Big-LaMa replaced the middle of three coins with another coin. Local and RORem cleared it. A quiet border with distinct objects just beyond it can favor local repair.

Read this before editing the companion. This branch starts at OpenFill `photocraft-v0.2.4`. PhotoCraft-specific UI and control code live in `photocraft/openfill_photocraft`. The shared engine is in `gimp-openfill/openfill`. Build the distribution with `tools/make_photocraft_zip.py`.

- Compare removal models on the same frozen input, selection and seed. Local suits smooth lighting, LaMa suits thin obstructions and paving, and Qwen Lightning can reconstruct recognizable geometry. RORem is a separate erase-trained model. Keep removal-only entries out of Image Edit and resolve suggestions against visible, available methods.
- Qwen removal receives the original photograph and a second copy highlighting the selected object in translucent red. Dedicated removers get the original source. FIBO uses a locally repaired guide. Preserve the RGB ICC profile from the editor export when constructing scratch layers. Untagged scratch layers shifted the color of a correct cable repair when copied into Adobe RGB.

- Existing-server mode defaults to a user-started ComfyUI at `127.0.0.1:8188`. Stock mode retains its managed engine. Model discovery reads actual loader choices and preserves their exact spelling, case, and path separators.
- For Qwen Image 2.1 editing, use `TextEncodeQwenImage21` and its source-aligned latent. Restore the original crop size before compositing. The Lightning checkpoint needs the exact published four sigmas plus the terminal zero.
- The document remains in reference slot 1. Use consecutive slots for attachments and derive the prompt labels from the selected model. The native and browser panels share reference state. Capture references at submission so later panel changes cannot affect an active edit.
- Send picked and dropped files through the same attachment validation in each panel. On Windows, scope file-drop registration to the reference control. The native callback releases each shell drop handle and queues work for Tk.
- Preserve the document exterior with a hard selection in the graph. Apply the saved soft mask once when PhotoCraft inserts the result. A source image passed through an encoder alone does not constrain geometry or guarantee reference adherence.
- Persist model visibility separately from model installation and selection. The panel's layout preferences store stable section IDs, which can be restored when an older profile is loaded.
- Keep unsent Generation control edits through polling. Send the changed values with the next job so the service can validate and save them before starting generation. Keep Engine settings on their own Save action.
- When appending results, exclude the pending layers from the input in a scratch duplicate. Verify the document's history and revision before committing the new choices. Keep existing thumbnail indices and selection stable within the same result set.
- Keep personal backend definitions, model inventories, test documents, configuration, logs, and weights out of public source and Git history.
- Pin model download URLs to immutable file revisions when the catalog supplies a checksum. Check the release URL against the expected size and checksum before distributing the ZIP.
- Keep the browser server on loopback and bypass the standard reverse lookup during bind. Slow hostname resolution can otherwise delay the panel opening.
- Run the shared and PhotoCraft companion unit tests. A live editor test should use a disposable PhotoCraft profile, verify exterior pixels and Discard, and leave existing ComfyUI jobs alone. Inspect renders separately for visual quality.
- In Remove, Nearby texture runs PhotoCraft's content-aware fill on a scratch copy with binary selection support. Apply the captured soft mask only when inserting the new result. This path works offline and may not cancel until the current scratch command finishes. Exclude earlier preview layers when appending another method.
- Local removal now checks unselected surroundings for smooth shading before texture synthesis. Harmonic completion preserves continuous lighting across large holes. Classify with an exclusion guard, then interpolate against the actual boundary. A guard used as the interpolation boundary left a visible shape. Add the softly blended removal margin once, retain the user's original selection, and compare exterior pixels against that prepared mask.
- Rebuild background uses the original-encoder FIBO Dev entry advertised with the remove capability. Gray-hole Turbo recreated fish, and a gray guide prepared directly from the photograph could recreate a larger subject. First produce a texture-filled clean plate. Send it to ComfyUI, mask the target for FIBO, and compare each proposal with the plate. Restrict edge-color estimation to unselected neighbors and generated interior pixels. Keep the sampled result if much of the proposal differs strongly in color. This check measures color disagreement, not object identity.
